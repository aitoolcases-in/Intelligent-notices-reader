# Accrevise brand pack

The Accrevise logo with the **growth-bar A**: vertical bars rise to a peak to form the first A, and a trend arrow climbs through it as the crossbar.

See `accrevise-brand-guide.pdf` (or `.png`) for the one-page guide.

## Colours

| Name | Hex | Use |
|---|---|---|
| Ledger green | `#034620` | Logo, headlines, green panels |
| Paper | `#F7F5EF` | Backgrounds; logo on green |
| Amber accent | `#E2B04A` | One highlight per design, never the logo |
| White | `#FFFFFF` | Backgrounds |

Type: Montserrat 800 for headlines, Source Serif 4 for body text and the tagline.

## Rules

- Clear space: at least the height of the word ACCREVISE on every side.
- Minimum size: full logo 160 px / 35 mm wide; below that use the mark; below 48 px use the small mark.
- Don't recolour, stretch, rotate, add effects, or rebuild the A or wordmark in a font.

The wordmark, ring and receipt are vector traces of the original logo artwork; the growth-bar A is drawn as exact geometry.
